# 🧱 Materials Consumption Project
### Проект для расчёта расхода строительных материалов и раствора  
**Автор:** Князев Алексей  
**Группа:** ИУ5-51Б  
**Курс:** Разработка интернет-приложений

---

## 📌 Описание проекта
Проект представляет собой систему для расчёта расхода строительных материалов и раствора.  
Состоит из нескольких независимых модулей: фронтенда, основного backend-сервера и асинхронного Django-сервиса вычислений.  
Приложение позволяет пользователю вводить параметры и получать точные вычисления расхода материалов.

---

## 🗂️ Репозитории проекта

### **1. materials-consumption-service**
Асинхронный сервис на Django, выполняющий расчёт расхода строительных материалов и раствора.  
Репозиторий:  
- https://github.com/Mopolop/materials-consumption-service

---

### **2. material-shop-frontend**
Frontend-часть проекта, реализованная на React.  
Обеспечивает UI для взаимодействия пользователя с системой.  
Репозиторий:  
- https://github.com/Mopolop/material-shop-frontend

Деплой (GitHub Pages):  
- https://mopolop.github.io/material-shop-frontend/

---

### **3. RIP (Основной backend-сервер)**
Основной сервер на Go (Golang), содержащий бизнес-логику проекта и взаимодействующий с другими сервисами.  
Репозиторий:  
- https://github.com/Mopolop/RIP
